# TANGIZ — бекенд (API)

Сервер на **Node.js + Express**, база **SQLite** через **Prisma**.
Одна БД — спільна для сайту й (згодом) Telegram-бота.

## Запуск (перший раз)

```bash
cd server
npm install
npx prisma migrate dev   # створює БД і застосовує схему
npm run seed             # наповнює демо-даними
npm run dev              # старт із авто-перезапуском → http://localhost:4000
```

Далі щодня достатньо `npm run dev`.

## Корисні команди

| Команда | Що робить |
|---|---|
| `npm run dev` | Сервер з авто-перезапуском при змінах |
| `npm start` | Сервер без перезапуску (прод-режим) |
| `npm run seed` | Перезаповнити БД демо-даними |
| `npm run db:reset` | Стерти БД і накотити міграції + seed заново |
| `npm run db:studio` | Візуальний перегляд БД у браузері (Prisma Studio) |

## Структура

```
server/
├─ prisma/
│  ├─ schema.prisma   # опис усіх таблиць (послуги, слоти, користувачі, записи, відгуки, профіль)
│  └─ seed.js         # початкові дані
└─ src/
   ├─ index.js        # Express-застосунок, підключення роутерів
   ├─ db.js           # єдиний Prisma-клієнт
   ├─ utils.js        # хелпери (нормалізація телефону/telegram, asyncHandler)
   └─ routes/         # по файлу на ресурс
```

## Telegram-бот (для власника)

Бот вмикається **лише** якщо в `.env` є `TELEGRAM_BOT_TOKEN`. Без токена сервер і сайт працюють як зазвичай.

Підключення:
1. Візьміть токен наявного бота у **@BotFather** (`/mybots` → бот → *API Token*).
2. Впишіть його в `server/.env`: `TELEGRAM_BOT_TOKEN="..."`.
3. (Опційно) перевірте стан бота — безпечно, лише читання:
   ```bash
   npm run bot:check
   ```
   Покаже, чи токен робочий і чи не «зайнятий» бот іншим кодом (вебхуком).
4. Запустіть сервер (`npm run dev`) — у логах з'явиться `🤖 Telegram-бот @... запущено`.
5. Лікар відкриває бота й надсилає **`/bind ваш_пароль`** (пароль власника) — цей чат стає отримувачем записів.

Далі кожен новий запис із сайту приходить лікарю з кнопками **✅ Підтвердити / ❌ Скасувати** — вони міняють статус у спільній БД (видно на сайті й в адмінці).

Команди лікаря в боті:
- **`/add`** — додати вільні години (обрати послугу → надіслати `ДД.ММ ГГ:ХХ`, можна кілька рядків);
- **`/slots`** — переглянути вільні слоти й видалити зайві (кнопка 🗑).

Слоти з бота й із сайту — це одні дані (спільна БД), тож усе синхронно автоматично.

## Далі за планом

- **Фаза 1** — підключити публічний сайт до цих ендпоінтів.
- **Фаза 2** — авторизація (клієнт: телефон+пароль; власник: логін+пароль), JWT.
- **Фаза 3** — адмінка: записи, зміна статусів, сторінка «очікують підтвердження», керування слотами.
- **Фаза 4** — Telegram-бот: власнику приходять нові записи; підтвердження/слоти з бота; усе синхронно з сайтом.

Логін власника (демо): `admin` / `admin`.
