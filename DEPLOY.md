# Як викласти TENGIZ в інтернет

Сайт, API і Telegram-бот працюють **одним процесом** на одному сервері: сервер віддає зібраний сайт,
відповідає на `/api`, тримає бота й таймери (автоскасування, нагадування), а база — це файл SQLite.
Тому потрібен хостинг, де процес працює **постійно** і є **диск, що не стирається** при оновленні.

**Рекомендація: [Railway](https://railway.com)** — заливає прямо з GitHub, сам робить HTTPS, є диски (volumes),
сервер не «засинає». Тариф Hobby — близько $5 на місяць, цього вистачає з запасом.

> Чому не Vercel/Netlify: там немає постійного процесу (бот і нагадування не працюватимуть) і
> немає диска для бази. До того ж безкоштовний Vercel заборонено використовувати для комерційних сайтів.

---

## 1. Домен

Домен куплено в **Cloudflare Registrar** (там само, де Syndicate), тож DNS уже на Cloudflare:
NS-сервери міняти не треба, а CNAME на «голий» домен Cloudflare підтримує.
Сайт хоститься **не** на Cloudflare (Workers не тримають постійний процес і файл бази), а на Railway.
Cloudflare лише направляє домен туди (крок 4).

> Якщо колись домен буде в іншого реєстратора: додайте його в Cloudflare (**Add a domain → Free**)
> і впишіть у реєстратора два NS-сервери, які покаже Cloudflare.

## 2. Telegram-бот для робочого сайту

Для робочого сайту — **окремий** бот `@Drdadvanibot`, не dev-бот.
1. У [@BotFather](https://t.me/BotFather): `/mybots` → `@Drdadvanibot` → **API Token** — скопіюйте.
2. ⚠️ Один токен може працювати лише в одному місці. Ніколи не запускайте локально сервер із
   робочим токеном — бот на сервері почне губити повідомлення.

### Якщо `@Drdadvanibot` уже працює в іншому місці (конструктор, інший сервер)

Токен може обслуговувати лише одна програма, тож старий бот вимикаємо, а «оболонка»
(`@Drdadvanibot`, аватар, чати з пацієнтами) лишається.

1. Перед переходом збережіть скриншоти меню й відповідей старого бота, якщо щось із них треба перенести.
2. **У день запуску**, одразу після деплою на Railway, у конструкторі відключіть бота
   (видаліть інтеграцію або токен). Наш сервер при старті й так знімає чужий webhook,
   але старий сервіс може повісити його назад.
3. Приберіть залишки старого бота: його меню команд, описи для окремих мов
   (вони перекривають наші). На своєму комп'ютері, у `server/.env` **тимчасово** впишіть
   робочий токен і запустіть:
   ```
   cd server
   npm run bot:setup -- --dry   # показати, що буде змінено
   npm run bot:setup -- --name  # застосувати (з назвою бота)
   ```
   Потім **поверніть** у `server/.env` токен dev-бота. Сервер локально з робочим
   токеном не запускайте.
4. Аватар змінюється лише в @BotFather (`/setuserpic`) з акаунта власника бота.
5. **Оплата старого бота.** Сам Telegram за ботів не бере грошей; платили сервісу, де бот був зібраний.
   Скасуйте підписку там (розділ «Тариф» / «Billing»), і **лише після** того, як переконаєтеся,
   що новий бот відповідає. Якщо в сервісі є функція «Видалити бота», вона зазвичай лише
   від'єднує токен, сам `@Drdadvanibot` у Telegram не зникне. Але для певності краще спершу
   «відключити», а не «видалити».

У пацієнтів, які писали старому боту, лишилися старі кнопки в історії чату. Наш бот на
натискання відповідає «Ця кнопка вже не діє. Надішліть /start», а «приклеєну» клавіатуру
внизу чату прибирає при першому ж повідомленні.

## 3. Railway

1. Зареєструйтеся на railway.com через GitHub, оберіть тариф Hobby.
2. **New Project → Deploy from GitHub repo →** `maulluv/Tangiz`.
3. У сервісі: **Settings → Source → Branch** — гілка, з якої викладати (`main`).
   Збірка й запуск уже описані в `railway.json` у репозиторії — нічого більше вказувати не треба.
4. **Диск для бази:** правою кнопкою на сервісі (або **+ Create**) → **Volume** → підключити до сервісу,
   **Mount path:** `/data`.
5. **Variables** (вкладка змінних) — додайте:

   | Змінна | Значення |
   |---|---|
   | `DATABASE_URL` | `file:/data/tangiz.db` |
   | `JWT_SECRET` | довгий випадковий рядок — згенерувати: `openssl rand -base64 48` |
   | `TELEGRAM_BOT_TOKEN` | токен `@Drdadvanibot` з кроку 2 |
   | `OWNER_USERNAME` | логін в адмінку, напр. `admin` |
   | `OWNER_PASSWORD` | пароль в адмінку (мін. 8 символів, **не** `admin`) |
   | `VITE_SITE_URL` | `https://tengiz.com.ua` (ваш домен, без `/` у кінці) |
   | `CLINIC_TZ` | `Europe/Kyiv` |
   | `BOOKING_CONFIRM_MIN` | `30` (хвилин на підтвердження запису в боті) |
   | `FOLLOWUP_DAYS` | `7` (через скільки днів після прийому лікар питає «як ви?», необов'язково) |
   | `GOOGLE_SERVICE_ACCOUNT` | JSON-ключ сервісного акаунта Google (весь вміст файлу) — для Google Calendar, див. `server/README.md` |
   | `GOOGLE_CALENDAR_ID` | gmail лікаря (id його календаря) |

   `PORT` не задавайте — Railway ставить сам.
   `OWNER_USERNAME`/`OWNER_PASSWORD` використовуються лише при першому запуску, коли база порожня.
6. Натисніть **Deploy**. У **Deployments → View logs** мають з'явитися рядки
   `🚀 TENGIZ API …` і `🤖 Telegram-бот @Drdadvanibot запущено.`
   З Google Calendar ще й `📅 Google Calendar: записи синхронізуються в …`.

## 4. Підключити домен

1. Railway: **Settings → Networking → Custom Domain** → ваш домен (без `www`). Якщо питає порт —
   залиште той, що він пропонує. Railway покаже записи: `CNAME` і часто ще `TXT` (`_railway-verify…`).
2. Cloudflare → домен → **DNS → Records → Add record** — додайте **кожен** запис, який показав Railway:
   - `CNAME`, Name `@`, Target — з Railway, **Proxy status: DNS only** (сіра хмаринка);
   - `TXT`, якщо Railway його дав — Name і Content як є.
   Якщо в DNS уже є старі `A`/`AAAA`/`CNAME` для `@` (напр. «паркування» від реєстратора) — видаліть їх.
3. `www`: додайте в Railway другий Custom Domain `www.ваш-домен` і так само його CNAME у Cloudflare
   (DNS only). Або без `www` зовсім — теж нормально.
4. Зачекайте, поки Railway покаже зелену галочку біля домену (5–30 хв, HTTPS-сертифікат робиться сам).
   ⚠️ Хмаринку не вмикайте (не «Proxied»), поки Railway не видав сертифікат, інакше перевірка не пройде.

## 5. Перший запуск

1. Відкрийте `https://ваш-домен/admin`, увійдіть з `OWNER_USERNAME` / `OWNER_PASSWORD`.
2. **Профіль клініки** — впишіть справжні телефон, Telegram, адресу.
3. Лікар у `@Drdadvanibot`: `/bind ВАШ_ПАРОЛЬ_ВІД_АДМІНКИ` → далі `/add`, щоб додати вільні години.
4. Зробіть пробний запис зі свого телефону від початку до кінця, потім скасуйте його.
5. Перевірте прев'ю: киньте посилання на сайт у Telegram «Збережене» — має бути картинка з лікарем.

## Оновлення сайту

Злити зміни в `main` і запушити — Railway сам перезбере й перезапустить. База на диску `/data`
не зачіпається, зміни структури бази застосовуються автоматично.

## Резервні копії

Railway: сервіс → вкладка **Backups** диска — увімкніть щоденні копії. Уся база — один файл
`/data/tangiz.db`.
